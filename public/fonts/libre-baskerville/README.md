# Libre Baskerville

Unmodified normal-style variable font, weight axis 400–700, including Latin Extended (Polish glyphs).

- Authors: The Libre Baskerville Project Authors / Impallari Type.
- Source: https://github.com/google/fonts/tree/main/ofl/librebaskerville
- Download: https://raw.githubusercontent.com/google/fonts/main/ofl/librebaskerville/LibreBaskerville%5Bwght%5D.ttf
- Upstream: https://github.com/impallari/Libre-Baskerville
- Retrieved: 2026-09-28.
- Bundled file: `LibreBaskerville-Variable.ttf` (original filename: `LibreBaskerville[wght].ttf`).
- SHA-256: `05a95421961341c5b2556285e8415df9db27dab4f4abe22b446b3c6a8b916c5d`.
- License: SIL Open Font License 1.1; the full copyright and license notice is included in `OFL.txt`.

The application hosts the font locally and waits for loading before drawing or exporting reels. No system installation, runtime font CDN or npm dependency is required.
